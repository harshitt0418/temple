# Shri Krishna Mandir — Official Temple Website Prototype

A refined, culturally rooted, client-ready frontend website prototype for **Shri Krishna Mandir** (Kurnool, Andhra Pradesh) and its associated Vedic school and community initiatives.

Designed following traditional Indian aesthetic principles, devotional sanctity, and accessibility standards for devotees of all ages.

---

## 🪔 Design Philosophy & Highlights

- **Culturally Rooted Aesthetics:** Warm cream/parchment background (`#F8F0E3`), deep sacred burgundy (`#5C1220`, `#7B1C2B`), and subtle gold ornamental accents (`#C8963C`).
- **Zero AI / Stock Temple Imagery:** Replaces generic stock photos with pure CSS & SVG sacred architecture, traditional Gopuram silhouettes, lotus motifs, and sanctum illumination.
- **Accessibility & Elderly Devotee Focus:** High-contrast legible typography (`Yatra One`, `Hind`, `Noto Serif Devanagari`), fluid sizing via `clamp()`, and clear visual hierarchies.
- **Interactive Devotional Modals:** Fully functional client prototype popups for:
  - 🪔 **Seva Booking** (Devotee details, Gotram, Nakshatram, Sankalpam, date selection)
  - 🙏 **Annadanam & Donations** (Contribution tiers, preset auspicious amounts)
  - 🎓 **Vedic School Enrolment** (Program selection, student details)
  - 🦚 **Festival Calendar & Passes** (Detailed schedules for Janmashtami, Govardhan Pooja, etc.)
  - ✉ **Temple Enquiry Desk** (Direct contact)

---

## 🏛️ Sections Included

1. **Notice Strip:** Marquee ticker with temple timings and live announcements.
2. **Navigation Header:** Sticky, scroll-responsive header with Sanskrit Om emblem and mobile drawer.
3. **Sacred Hero:** Devotional sanctum radiance, divine invocation, and quick timings pill (Morning, Evening, Aarti).
4. **About the Mandir:** Temple history since 1987, architectural details, and annual devotee reach.
5. **Darshan, Pooja & Seva:** 4-session daily schedule, interactive seva booking cards, and Annadanam support banner.
6. **Sacred Festivals:** Featured Janmashtami Mahotsavam banner with peacock motif and full festive calendar.
7. **Temple Gallery:** Ornamental masonry showcase ready for high-resolution photography.
8. **Vedic Cultural School:** Weekend Sanskrit, Bhajan, and Yoga programs for youth and families.
9. **Devotee Testimonials:** Reflections of faith from local devotees.
10. **Plan Your Visit:** Directions (Bus, Rail, Road), guidelines, map placeholder, and contact links.
11. **Cultural Footer:** 4-column footer with timings, quick links, and peace mantra.
12. **Floating Seva Trigger:** Responsive floating button with pulsing ring for quick seva reservations.

---

## 🚀 Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite 8
- **Styling:** CSS Modules with CSS Custom Properties (Design Tokens)
- **Typography:** Google Fonts (`Yatra One`, `Hind`, `Noto Serif Devanagari`, `Cormorant Garamond`)
- **Icons & Graphics:** Pure Inline SVG & Unicode sacred motifs

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
git clone https://github.com/harshitt0418/temple.git
cd temple
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
